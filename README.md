# Marymar — лендінг авторських техкарт тортів

Односторінковий сайт, де кондитерка Марія ([@marymar.cake](https://www.instagram.com/marymar.cake/)) продає техкарти тортів у форматі PDF.

**Сайт:** https://shurachuh-dev.github.io/LandingMarryMar/

Сайт зроблено на звичайних HTML, CSS і JavaScript. Він не потребує конструктора, бази даних чи збірки.

---

## Як оновлюється сайт

Сайт розміщено безкоштовно на **GitHub Pages**. Після кожного збереження змін у гілку `main` сайт оновлюється сам приблизно за 1 хвилину. Якщо бачите стару версію, оновіть сторінку (Ctrl+F5).

## Як подивитися сайт на своєму комп'ютері

1. Відкрийте папку проєкту в терміналі.
2. Запустіть:
   ```
   powershell -ExecutionPolicy Bypass -File serve.ps1
   ```
3. Відкрийте в браузері http://localhost:8080. Щоб зупинити сервер, натисніть `Ctrl+C`.

Для швидкого перегляду можна двічі клацнути `index.html`, але сервер точніше показує, як сайт працюватиме в інтернеті.

## Де що змінювати

Усі тексти, ціни й товари лежать у файлі **`index.html`**. Відкрийте його в редакторі (наприклад, VS Code) і знайдіть потрібне місце пошуком `Ctrl+F`.

### Ціни

Знайдіть стару ціну, наприклад `300 грн`, і замініть її на нову.

```html
<span class="price">300 грн</span>
```

Вікно оплати бере ціну з картки, тому її досить змінити в одному місці.

| Що | Тестова ціна |
|---|---|
| Окрема техкарта (кожен смак) | 300 грн |
| Збірка смаків | 750 грн |
| Пакет усіх техкарт | 1400 грн |

### Тексти

Знайдіть текст пошуком і змініть його, не чіпаючи теги навколо (`<p>`, `<h2>` тощо).

### SEO: заголовок сторінки та опис для Google

На початку `index.html`, у рядках з `<title>` і `<meta name="description">`.

- Title: до 60 знаків.
- Description: до 160 знаків.

### Додати новий смак

Скопіюйте в `index.html` один блок `<article class="product">…</article>` цілком і змініть у копії:

- назву в `<h3>`;
- шари торта в списку `<li>`;
- ціну;
- `data-buy="…"`: короткий унікальний ідентифікатор латиницею, наприклад `data-buy="medovyk"`;
- `aria-label` кнопки: «Купити техкарту <назва>»;
- шляхи до фото й опис фото (`alt`).

Новий смак сам з'явиться у вікні оплати в списку «Додати інші смаки».

### Фото

Фото лежать у папці `assets/img/`. Кожне фото збережено в трьох файлах:

| Файл | Для чого |
|---|---|
| `назва.jpg` | запасний варіант для старих браузерів |
| `назва.webp` | основний, легкий формат |
| `назва-480.webp` (у головного фото — `-640` і `-800`) | зменшені копії для телефонів |

Щоб замінити фото, замініть **усі три файли** з тими самими іменами. Якщо замінити лише `.jpg`, сучасні браузери й далі показуватимуть старе фото з `.webp`.

Конвертувати в WebP можна безкоштовно на squoosh.app.

### Слайди «Що всередині техкарти»

Слайдер біля блоку «Що всередині техкарти» показує 4 сторінки техкарти: інгредієнти, коржі, крем, збирання. Зараз це **демо-сторінки**, намальовані для прикладу.

Щоб поставити справжні сторінки з PDF, замініть для кожного слайда (`inside-step1` … `inside-step4`) **чотири файли** з тими самими іменами:

| Файл | Розмір |
|---|---|
| `inside-stepN.jpg` | 772 × 724 |
| `inside-stepN.webp` | 772 × 724 |
| `inside-stepN-480.webp` | 480 × 450 |
| `inside-stepN-1100.webp` | 1100 × 1032 |

Пропорції мають бути такі самі (772 : 724), інакше краї зображення обріжуться. Підписи слайдів і опис фото (`alt`) змінюються в `index.html`, у блоці `<section … id="inside">`. Слайди перемикаються кожні 2 секунди; інтервал задано в `js/main.js`, у функції `initTcSlider` (`DELAY = 2000`, у мілісекундах), а тривалість переходу — у стилях у `index.html`, у правилі `.tc-slide` (`transition`).

### Кольори

Кольори задано в `index.html`, на початку блоку `<style>` (у `<head>`), у блоці `:root`. Головний бордовий колір — `--accent: #6A1027`.

## Оплата (зараз демо)

Кнопка з кошиком відкриває вікно оплати: товар, email, спосіб оплати, згода й сума. Зараз це **демонстрація**: гроші не списуються, email нікуди не надсилається і ніде не зберігається.

Для справжніх продажів треба підключити платіжний сервіс з автоматичним надсиланням PDF (наприклад, WayForPay, LiqPay або Monobank). Місце для цього в коді позначене коментарем у файлі `js/main.js`, у функції `initCheckout`:

```
// Демо: імітуємо обробку платежу. Тут пізніше буде виклик платіжного сервісу.
```

## Підписка на новинки (зараз демо)

Форма «Дізнавайтеся першими про нові техкарти» стоїть у каталозі, під пакетами. Зараз вона лише показує «Дякуємо, ви в списку!», email нікуди не надсилається.

Щоб справді збирати адреси, підключіть один із сервісів: **Formspree** (найпростіше, листи приходять на пошту), **Google Forms** (адреси збираються в Google Таблицю) або **MailerLite** (повноцінні розсилки). Покрокова інструкція й готовий код для кожного варіанта — у коментарі над функцією `initSubscribe` у файлі `js/main.js`. Потрібно замінити лише функцію `send`.

## Структура проєкту

```
index.html        уся сторінка: тексти, ціни, товари, вікно оплати, а також усі стилі (блок <style> у <head>, кольори на його початку)
js/main.js        інтерактив: FAQ, слайдер техкарти, калькулятор, підписка, меню, вікно оплати
assets/img/       фото (jpg + webp)
assets/fonts/     шрифти Manrope, Cormorant Garamond, Cormorant SC, Marck Script
serve.ps1         локальний сервер для перевірки
```
